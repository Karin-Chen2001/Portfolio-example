活動 08：從電腦版變成手機版

使用 Media Queries（媒體查詢），讓同一個網頁在電腦、平板、手機上都能清楚閱讀。

👉 請拉動瀏覽器視窗寬度，或按 F12 切換成手機模式，觀察版面變化。

一、彈性圖片

img, svg { max-width: 100%; height: auto; }

二、響應式卡片

電腦版

寬度大於 900px 時，卡片排成 3 欄。

平板版

寬度 600～900px 時，卡片排成 2 欄。

手機版

寬度小於 600px 時，卡片變成 1 欄，導覽列改成直排。

三、Media Query 程式碼

/* 預設：電腦版 3 欄 */
.cards { display: grid; grid-template-columns: repeat(3, 1fr); gap: 20px; }

/* 平板 */
@media (max-width: 900px) {
  .cards { grid-template-columns: repeat(2, 1fr); }
}

/* 手機 */
@media (max-width: 600px) {
  .cards { grid-template-columns: 1fr; }
  .navbar { flex-direction: column; }
}

四、斷點整理

裝置 斷點 卡片欄數 導覽列
電腦> 900px3 欄橫排
平板≤ 900px2 欄橫排
手機≤ 600px1 欄直排、按鈕加大

五、心得

手機螢幕窄，所以要把多欄改成單欄、放大可點擊範圍，並用 viewport meta 讓瀏覽器以裝置實際寬度顯示。
