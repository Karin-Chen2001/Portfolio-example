數位科技概論作業 - 網頁開發與專案實務

本專案為數位科技概論課程之核心作業成果，旨在展示現代網頁前端開發技術、版本控制流程以及莫蘭迪美學視覺設計的整合實作。

📌 專案設計理念與架構

以簡約高質感且沉穩的深黑與莫蘭迪咖啡色為主調，著重於響應式排版（Responsive Design）與優質的用戶互動體驗。

🛠️ 使用技術與開發重點

  • GitHub 版本控制：使用 Git 進行專案版本控管、程式碼同步與架構優化。
  • HTML5 語意化結構：打造清楚且利於搜尋引擎優化（SEO）的內容架構。
  • CSS3 莫蘭迪視覺與響應式系統：採用 CSS Grid 與 Flexbox 實現跨裝置流暢適配。
  • JavaScript 動態互動：包含大頭照即時預覽、單頁應用（SPA）無縫頁面切換機制。
