數位科技概論作業 - 網頁開發與專案實務

本專案為數位科技概論課程之核心作業成果，旨在展示現代網頁前端開發技術、版本控制流程與視覺設計的整合實作。

📌 專案設計理念與架構

採用簡約文青白色調搭配明亮鮮豔的標題色彩，著重於直覺的閱覽體驗與排版佈局。

🛠️ 使用技術與開發重點

  • GitHub 版本控制：使用 Git 進行專案版本控管與程式碼同步。
  • HTML5 語意化結構：打造清楚且利於搜尋引擎優化（SEO）的內容架構。
  • CSS3 響應式系統：採用 CSS Grid 與 Flexbox 實現流暢跨裝置適配。
