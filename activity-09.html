活動 09：先機檢，再修正無障礙問題

符合高對比度規範的文字，搭配語意化標籤與標題階層，能讓螢幕閱讀器與所有使用者更輕鬆閱讀內容。

一、機檢工具與結果

使用的檢測工具：

  • Chrome Lighthouse（Accessibility 分數）
  • WAVE 瀏覽器擴充功能
  • WebAIM Contrast Checker（色彩對比）

修正前檢測出的常見問題：圖片缺少替代文字、文字對比不足、表單欄位沒有標籤、標題層級跳級、缺少 lang 屬性。

二、問題與修正對照表

機檢發現的問題與修正方式
問題修正前修正後
1. 文字對比不足 color: #aaaaaa 在白底，對比約 2.32:1（未達 4.5:1） color: #595959 在白底，對比約 7.0:1（達 AA、AAA）
2. 圖片沒有替代文字 <img src="pond.jpg"> <img src="pond.jpg" alt="校園中庭的水池與睡蓮">
3. 表單欄位沒有標籤 <input type="text"> <label for="name">姓名</label><input id="name">
4. 標題層級跳級 h1 之後直接用 h4 依序使用 h1 → h2 → h3
5. 沒有語言屬性 <html> <html lang="zh-Hant">
6. 用 div 當按鈕、鍵盤無法操作 <div onclick="...">送出</div> <button type="submit">送出</button>
7. 看不到鍵盤焦點 outline: none :focus-visible { outline: 3px solid #b45309; }
8. 連結文字不清楚 <a href="...">點這裡</a> <a href="...">查看活動 05 成果</a>

聯絡表單（已修正）

所有欄位都有標籤，文字對比充足，可用鍵盤 Tab 鍵操作。

四、修正重點程式碼

<html lang="zh-Hant">

<a class="skip-link" href="#main">跳到主要內容</a>
<main id="main"> ... </main>

/* 對比 */
.muted { color: #595959; }   /* 白底 7.0:1 */

/* 焦點 */
a:focus-visible, button:focus-visible {
  outline: 3px solid #b45309;
  outline-offset: 3px;
}

五、心得

機檢可以快速找出明顯錯誤，但仍需要用鍵盤操作與閱讀順序實際測試。無障礙設計不只幫助身障者，也讓戶外強光、年長者與所有使用者閱讀更舒服。
