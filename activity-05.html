活動 05：同一份內容，換一種風格

透過 CSS 改變色彩、字體與背景，就能為網頁打造完全不同的氛圍與風格感。

一、風格切換實作

下方卡片的 HTML 完全相同，只有最外層 id="demo" 的 class 不同。

二、CSS 程式碼（風格 A 範例）

.theme-minimal {
  background: #ffffff;
  color: #1f2933;
  font-family: "Noto Sans TC", sans-serif;
  border: 1px solid #d0d7de;
}
.theme-minimal h3 { color: #0b6bcb; }
.theme-minimal a.btn {
  background: #0b6bcb;
  color: #fff;
  border-radius: 6px;
}
.theme-minimal a.btn:hover { background: #084f96; }

三、本活動用到的選擇器

選擇器對照表
類型寫法作用
元素選擇器h3 { }所有 h3 標題
class 選擇器.tag { }套用到 class="tag" 的元素
id 選擇器#demo { }唯一一個 id="demo" 的元素
後代選擇器.theme-neon h3 { }neon 風格內的 h3
偽類別a.btn:hover { }滑鼠移上去時的樣式

四、心得

同樣的內容換成不同字體、顏色與邊框後，給人的感覺差很多：簡約風適合資訊清楚的頁面，復古風有紙本質感，霓虹風則帶有科技感。
