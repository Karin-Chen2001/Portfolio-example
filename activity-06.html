活動 06：我的網站適合哪種版型？

先了解每個元素都是一個「盒子」，再比較不同版型的優缺點，最後決定自己的網站要用哪一種。

一、Box Model 盒模型

由外而內： margin 外距 border 邊框 padding 內距＋content 內容

這是一個盒子：content 寬 200px，padding 20px，border 8px，margin 24px。
.box {
  margin: 24px;
  border: 8px solid #c2410c;
  padding: 20px;
  width: 200px;
}

box-sizing 差異

兩個盒子都設定 width: 200px; padding: 20px; border: 8px，實際佔用寬度卻不同：

content-box

實際寬度： px

border-box

實際寬度： px

* { box-sizing: border-box; }  /* 常用設定：width 已包含 padding 與 border */

二、三種常見版型

版型 A：單欄式

Header 導覽列
內容區塊 1
內容區塊 2
Footer

版型 B：雙欄式（側欄＋主內容）

Header 導覽列
側欄／目錄
主要內容
Footer

版型 C：卡片式

Header 導覽列
卡片 1
卡片 2
卡片 3
Footer
.two-col { display: flex; }
.two-col .side { flex: 0 0 28%; }
.two-col .main { flex: 1; }
.card-row { display: flex; flex-wrap: wrap; }
.card-row .b { flex: 1 1 28%; }

三、版型比較與選擇

版型優點缺點適合的網站
單欄式閱讀動線單純、手機友善電腦版寬螢幕留白多文章、自我介紹
雙欄式目錄與內容同時可見手機需改成上下排列課程筆記、文件
卡片式一眼瀏覽多個項目內容太長時不易閱讀作品集、作業目錄

我的選擇

我的作品集要展示多份課程作業，所以首頁選擇「卡片式」，每張卡片代表一個專案；各活動內頁則使用「單欄式」，讓說明與成果可以由上往下閱讀。
